# 엑셀 데이터 전처리 시스템

엑셀 데이터를 업로드하고 다양한 형식(GBIF, 네이버백과사전, 바이오원)으로 변환할 수 있는 웹 애플리케이션입니다.

## 기능

- 📁 엑셀 파일 업로드 (.xlsx, .xls)
- 📊 데이터 미리보기
- ⚙️ 3가지 전처리 옵션:
  - GBIF로 변환
  - 네이버백과사전으로 변환
  - 바이오원으로 변환
- 💾 처리된 데이터를 엑셀 파일로 저장

## 설치 방법

1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
streamlit run app.py
```

브라우저가 자동으로 열리며 `http://localhost:8501`에서 애플리케이션을 확인할 수 있습니다.

## 사용 방법

1. **파일 업로드**: 왼쪽 사이드바에서 엑셀 파일을 선택합니다.
2. **데이터 확인**: 업로드된 데이터의 미리보기를 확인합니다.
3. **전처리 선택**: 원하는 변환 형식을 선택합니다.
4. **전처리 실행**: 선택한 옵션으로 데이터를 변환합니다.
5. **파일 저장**: 변환된 데이터를 엑셀 파일로 저장합니다.

## 전처리 옵션 설명

### GBIF 변환
- GBIF(Global Biodiversity Information Facility) 표준 형식으로 변환
- 생물다양성 데이터의 국제 표준 형식

### 네이버백과사전 변환
- 네이버백과사전에 적합한 한글 중심 형식으로 변환
- 한글명, 학명, 영문명 등 포함

### 바이오원 변환
- BioOne 데이터베이스 형식으로 변환
- 학술 논문 및 참고문헌 정보 포함

## 주의사항

- 전처리 함수는 기본 매핑 로직을 사용합니다. 실제 데이터 구조에 맞게 `preprocessors.py` 파일의 매핑 로직을 수정해야 할 수 있습니다.
- 대용량 파일의 경우 처리 시간이 걸릴 수 있습니다.
